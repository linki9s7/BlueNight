# BGM 一覧と設計（v1）

## 聴き心地のルール（すべての曲に共通）

| 観点 | ルール | 実装 |
| --- | --- | --- |
| 周波数 | 話し声の帯域（500 Hz〜2 kHz）を少し下げて BGM を一歩後ろへ。耳に刺さる高音とお腹に響く重低音を取る | マスターで 1 kHz 付近を −2.5 dB（Q 0.6）、40 Hz 以下をカット、8 kHz から上をなだらかに丸める（`blue_song.master_eq`） |
| 音量の安定 | 急に大きく・小さくならない | ゆるいコンプレッサー（比 2.2、アタック 30 ms、リリース 350 ms）を通しの音にかける（`gentle_compressor`）。ラウドネスは全曲 −16 LUFS にそろえる |
| 旋律 | 主張させない。和音の循環が主役 | 旋律パートは伴奏より小さく、ローパスで丸める。タイトル曲だけは旋律をはっきり聴かせる |
| 構成 | なだらかに。サビで急に盛り上げない | A と B の差は「楽器が 1 つ増える」程度 |
| テンポ | 心拍に近い BPM 60〜80 | 探索曲はすべて 60〜80。影を追う場面だけ 100 |
| アタック | 強いドラムを避ける | ブラシ・リム・シェイカー中心。キックはごく弱く。環境音は別トラックで重ねる |
| 音色 | アコースティック、こもったピアノ、ローファイなエレピ、薄いパッド | ピアノは 5.5〜7 kHz のローパスでアップライト寄りに |
| ループ | 継ぎ目で途切れない | ループ部分を 2 回演奏して 2 回目を切り出し、終わり 50 ms を頭の直前の音へクロスフェード。`check_loops.py` で確認 |

## モチーフ

- **ルリのテーマ**：ソ・ド・レ・ミ（D♭ なら A♭–D♭–E♭–F）。上がりきらずに止まる＝「言いかけて、やめる」。各章の曲に移調して入れる。最終章でだけ先へ続き、主和音へ解決する。
- **影のモチーフ**：半音で沈むため息（E マイナーなら B–C–B、A–G）。影を追う場面と、影の言葉の場面で使う。

## 環境音（`ambience.py`、−26 LUFS）

### ミックスのルール

- **主役は 1 つ**。ほかは空間を埋める背景として薄く重ねる。音量は均一にしない。
- 主役は面のノイズではなく **出来事の積み重ね** で作る（雨粒 1 粒、波 1 つ、虫 1 匹）。
- **ノイズは隠し味**：主役より 12〜15 dB 小さく（おおよそ主役の 20〜30% の大きさ）。
- **左右に散らす**：主役は真ん中〜少し片側、背景は広く。
- **エフェクトは控えめ**：リバーブは使わず、遠さはローパスと音量で表す。
- 層ごとの音量は聞こえ方の音量（LUFS）で測ってそろえ、`ambient_manifest.json` に記録する。
- ループは「円」で作る（周期的なノイズ＋はみ出した出来事は頭へ回り込む）ので、継ぎ目にクロスフェードが要らない。

- **素材は録音を優先**（`Tools/Music/sources/`、CC0・CC BY）。短い録音は、ランダムな位置の断片を少しずつ速さを変えて重ね、
  繰り返しに聞こえない長い音にする。波や車は出来事ごとに新しく材料を作り、同じ断片を使い回さない
  （1 秒ごとの区間どうしの似かよりが 0.25 以下になることを確認）。

## Unity での鳴らし方（ローカル環境で実装する）

- `Assets/006_Audio/BGM/music_manifest.json` に、各曲の BPM・拍子・前奏とループの長さ・レイヤーのファイル名がある。
- 前奏ファイルを鳴らし、`AudioSettings.dspTime` で前奏の終わりぴったりにループファイルを `PlayScheduled` してループ再生する。
- `shadow_chase` は 3 レイヤーを同時に再生し、音量だけを 1〜2 秒で上げ下げする（仕様書 8.3）。
