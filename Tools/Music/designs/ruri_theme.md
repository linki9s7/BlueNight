# 曲の設計書：ルリのテーマ（30 秒スケッチ）

| 項目 | 内容 |
| --- | --- |
| 使う場面 | タイトル画面、章の始まりの遠景カット。のちに各曲へモチーフとして織り込む |
| 感情 | 静かな青い夜。少し寂しいが、ランタンの灯りのような温かさもある。「言いかけて、言えない」ためらい |
| テンポ | ♩= 72 前後。フレーズの終わりでわずかに緩める（ルバート） |
| 拍子・キー | 4/4、D♭ メジャー（ピアノでいちばん柔らかく暗めに響く調のひとつ） |
| 楽器 | ピアノ独奏（スケッチ段階）。本番ではチェロかグロッケンを一部に重ねる案 |
| 長さ | 約 30 秒（前奏 1 小節＋テーマ 8 小節＋余韻） |

## モチーフ（ルリのテーマ）

```
A♭ → D♭ → E♭ → F（のばす）… E♭ → D♭（ため息のように下がる）
```

- 上がりきらずに止まる形で「言いかけて、やめる」感じを出す。
- 1 拍目を休符にして、少し遅れて言葉を探すように入る。

## 和音進行

| 小節 | 和音 | 役割 |
| --- | --- | --- |
| 1 | D♭maj9 | 前奏。左手の分散和音だけ |
| 2–5 | D♭maj9 → A♭/C → B♭m9 → G♭maj7 | 問いかけのフレーズ。落ち着いて下がっていく |
| 6–9 | D♭maj9 → A♭/C → B♭m7・E♭m9 → A♭sus4 | 答えようとして、いちばん高い音（A♭）まで届く |
| 10 | G♭maj7(#11) | 解決せずに終わる。「言えなかった」まま、余韻だけ残す |

## 演奏の味付け

- 強弱：フレーズの山（小節 7 の A♭）に向かって少しずつ強く、終わりは弱く。左手は右手より控えめ。
- タイミング：1 音ずつ ±10 ms 程度揺らす。メロディは伴奏よりほんの少し遅れて鳴らす（歌うように）。
- ペダル：和音が変わる瞬間に踏み替える（レガートペダル）。
- 伴奏の形を小節ごとに少しずつ変え、同じ型を機械的に繰り返さない。

## 仕上げ

- 残響：やや広めの部屋（約 2 秒）。
- テープの揺れ（ごくわずかな音程の揺らぎ）と、うっすらとしたヒスノイズ。
- 高音を少しだけ丸め、夜の録音らしい質感に。
- ラウドネス：-16 LUFS 目安、ピーク -1 dB 以下。
