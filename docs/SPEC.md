# BlueNight ゲーム仕様書（ドラフト v0.1）

> 本書は「BlueNight」の初期仕様書です。『アンリアルライフ（UNREAL LIFE）』のような
> **ドット絵 × 静かな夜の街 × 記憶をたどる物語** という体験をイメージしていますが、
> キャラクター・世界観・ストーリー・メカニクスはすべてオリジナルとして設計します。
> 「仮」と書いた項目は、今後の相談で決める前提の値です。

---

## 1. ゲーム概要

| 項目 | 内容 |
| --- | --- |
| タイトル | BlueNight（仮） |
| ジャンル | 2D 横スクロール・ストーリーアドベンチャー（探索＋謎解き） |
| 視点 | サイドビュー（横から見た断面的な街並み） |
| プラットフォーム | Windows（Steam 想定）。将来的に Switch／スマホも検討 |
| プレイ時間 | 本編 3〜4 時間（全 5 章）。最初の目標は第 1 章のみ（20〜30 分） |
| 対象 | 雰囲気のある物語ゲーム、ドット絵、やさしい謎解きが好きな人 |
| エンジン | Unity 2022.3.34f1（既存プロジェクトを利用）＋ URP 2D |
| 言語 | 日本語（将来的に英語） |

### 1.1 コンセプト（一言で）

**「明けない青い夜の街で、灯りに照らされたモノの『記憶』をたどり、失くした約束を思い出す物語」**

### 1.2 体験の柱

1. **静けさと余韻** — 青い夜、街灯、雨上がりの路面の反射。急かされない、眺めるだけで楽しい画面。
2. **モノに残る記憶** — 道端のベンチ、止まった時計、誰かの傘。照らすと過去の一場面が見える。
3. **やさしい謎解き** — 見た記憶の内容が答えのヒントになる。理不尽な詰まりはつくらない。
4. **少しずつ明かされる物語** — 主人公の失った記憶と、この街がなぜ夜のままなのかが重なっていく。

## 2. 世界観・ストーリー（仮）

### 2.1 舞台

- 夜が明けなくなった小さな港町「アオヨ町（仮）」。
- 空はいつも深い青で、町の人々はどこか眠たげに、昨日と同じ夜を繰り返している。
- 町の中のモノには、持ち主や出来事の記憶が **「残光（ざんこう）」** として宿っている。
- エリア：バス停と商店街 → 雨の路地裏 → 夜の学校 → 灯台と港 → 夜明けの丘（最終章）

### 2.2 あらすじ

終バスの止まったバス停で目を覚ました少女・**ルリ**。自分の名前以外は何も覚えていない。
手には、青く光る古いランタンが一つ。そのランタンでモノを照らすと、そこに残った記憶が浮かび上がる。

ランタンの光に寄ってきた、しゃべる小さな蛾の **ネム** と一緒に、ルリは町を歩き始める。
人々の小さな困りごとを記憶の手がかりで解いていくうちに、ルリはこの町の「明けない夜」と、
自分が誰かと交わした **「夜明けに、あの丘で」** という約束に近づいていく。

### 2.3 テーマ

- 記憶と忘却、そして「手放すこと」
- 終わらない夜は、誰かが前に進めないでいることの象徴

### 2.4 主要キャラクター

| 名前 | 役割 | 特徴 |
| --- | --- | --- |
| ルリ | 主人公 | 物静かな少女。青いマフラー。感情表現は控えめで、仕草で見せる。 |
| ネム | 相棒 | 手のひらサイズの蛾。おしゃべりでツッコミ役。ランタンの光が好き。ゲーム中のヒント役も兼ねる。 |
| 運転手 | 導き手 | 動かないバスの運転手。章の区切りでルリを次のエリアへ送る。 |
| 町の人々 | 各章の依頼者 | 商店のおばあさん、傘をなくした学生、灯台守など。それぞれ一つの「止まった記憶」を持つ。 |
| ？？？ | 約束の相手 | 物語の核心。正体は最終章で明かされる。 |

## 3. ゲームシステム

### 3.1 基本ループ

```
エリアを探索する
  → 人と話す／困りごとを知る
  → ランタンでモノを照らし、記憶（残光）を見る
  → 記憶から手がかりを得て、アイテムを使う・仕掛けを解く
  → 町の人の「止まった記憶」が動き出す（小さなご褒美演出）
  → 新しい場所が開く／物語が進む
```

### 3.2 移動・探索

- 左右移動（歩き／小走り）。ジャンプは無し（落ち着いた操作感を優先）。
- 扉・階段・はしごは「調べる」で移動。画面端で隣の画面へ切り替え（1 画面〜横 3 画面程度のスクロール部屋）。
- 調べられる対象に近づくと、頭上に小さなアイコン（💬会話／🔍調べる／🏮照らす）を表示。

### 3.3 ランタン（コアメカニクス）

- **照らす**：対象に近づいて「照らす」ボタン。記憶を持つモノは淡く青く光って反応する。
- **残光（記憶）を見る**：照らすと、その場で過去の情景が半透明のシルエットとして再生される
  （画面全体の色調が変わり、過去の人物が影絵のように動く短い演出 5〜20 秒）。
- **記憶のかけら**：見た記憶は「記憶帳」に自動記録され、いつでも見返せる。
  謎解きの答え（暗証番号、物の置き場所、人の名前など）はここに残る。
- **ランタンの強さ（章が進むと解放）**：
  - 第 1 章：近くのモノだけ照らせる
  - 第 3 章：「もっと昔」を照らせる（同じモノの、さらに前の記憶が見える）
  - 第 4 章：光を遠くに投げ、離れた場所を照らせる

### 3.4 謎解き

- 原則として **「記憶で見た情報を、現在の世界で使う」** 形式。例：
  - 止まった時計の記憶で「針が何時を指していたか」を知り、時計を合わせる
  - 傘の記憶で持ち主の学生の顔と居場所を知り、傘を届ける
  - 記憶の中の人物がしていた順番どおりに、自販機のボタンを押す
- アイテムは少数（同時所持 8 個まで）。「使う」は対象の前でアイテムを選ぶだけ。組み合わせは無し。
- 詰まり対策：ネムに話しかけると段階的なヒント（3 段階）。ゲームオーバーは無し。

### 3.5 会話

- 画面下部のウィンドウに 1 文字ずつ表示。顔グラフィックは小さめ（48×48 px）。
- 選択肢は少数で、物語の分岐は無し（一本道）。会話の雰囲気が変わる程度。
- 一部の会話はウィンドウを出さず、キャラの頭上に吹き出しで表示（町の生活音的なつぶやき）。

### 3.6 収集要素（任意）

- 町中に隠れた「小さな記憶」（本筋に関係ない住人の思い出）を集めると、記憶帳のページが埋まる。
- 全部集めるとエンディング後に短い追加シーン。

### 3.7 セーブ

- オートセーブ（エリア移動時・謎を解いたとき）＋ メニューから手動セーブ（3 スロット）。

## 7. アート仕様（ドット絵）

### 7.1 解像度

| 項目 | 値（仮） |
| --- | --- |
| 内部解像度 | **480 × 270 px**（16:9。1920×1080 / 3840×2160 では整数倍 ×4 / ×8 でぴったり表示。1280×720 など割り切れない解像度では ×2 で表示し周囲に黒帯） |
| Pixels Per Unit | 16 |
| タイルサイズ | 16 × 16 px |
| 主人公の身長 | 約 32〜36 px |
| 顔グラフィック | 48 × 48 px |
| フォント | 日本語ドットフォント（候補：DotGothic16〈OFL〉、PixelMplus〈M+ ライセンス〉）※ライセンス確認の上採用 |

### 7.2 カラー・雰囲気

- 基調色は **深い青〜群青〜紺**。差し色は街灯・窓明かり・ランタンの **暖色（橙・黄）** と記憶の **水色の発光**。
- パレットは 32〜48 色程度に制限して統一感を出す（候補：自作パレットを `Assets/005_Textures/Palette.png` に用意）。
- 「記憶」シーンは彩度を落とし、水色のモノトーン＋ノイズ／にじみ表現。
- 背景は 3〜4 層のパララックス（遠景の空・街並み・近景・手前の影）。

### 7.3 アニメーション

| 対象 | パターン |
| --- | --- |
| ルリ | 待機 4f、歩き 8f、小走り 6f、調べる 4f、照らす 6f、振り向き 2f |
| ネム | 羽ばたき 4f（常時ふわふわ追従） |
| NPC | 待機 2〜4f＋固有の仕草 1 種 |
| 環境 | 雨、水たまりの波紋、街灯の明滅、湯気、蛾の群れ など |

### 7.4 ライティング

- URP 2D ライトを使用。全体は暗めの Global Light（青）＋ 街灯・窓・ランタンの Point Light（暖色）。
- ランタンの光は主人公に追従し、照らした範囲だけ背景のディテールが見える演出を入れる。
- ドット感を崩さないよう、ライトの影響はシンプルに（ノーマルマップは使わない予定）。

| 種類 | 方針 |
| --- | --- |
| BGM | ピアノ・ローファイ・アンビエント中心。エリアごとに 1 曲＋記憶シーン用 1 曲。全 8〜10 曲 |

## 9. 技術仕様

### 9.1 現在のプロジェクト状態

- Unity 2022.3.34f1、URP 14.0.11（**3D 用テンプレート**：Plane / Directional Light のみのシーン）。
- 入力は旧 Input Manager（`activeInputHandler: 0`）。
- スクリプトはまだ無し。

### 9.2 必要な変更（M0 で実施）

1. URP を **2D Renderer**（`Renderer2D` アセット）に切り替え、URP アセットに設定する。
2. パッケージ追加：
   - `com.unity.2d.sprite`、`com.unity.2d.tilemap`（＋任意で `com.unity.2d.tilemap.extras`）
   - `com.unity.inputsystem`（ゲームパッド・キー設定変更のため）
   - `com.unity.cinemachine`（カメラ追従・部屋の境界制御）
3. Main Camera に **Pixel Perfect Camera**（480×270, PPU 16）を設定。
4. スプライト取り込み設定の標準化：Filter Mode = Point、Compression = None、PPU = 16。
5. 不要な 3D 要素（Plane、Ground.mat、TutorialInfo）を整理。

### 9.3 フォルダ構成（既存の番号付き構成を踏襲）

```
Assets/
  001_Scenes/        Title, Chapter01_BusStop, Chapter01_Shopping, ...
  002_Scripts/
    Core/            GameManager, SaveSystem, SceneLoader, Flags
    Player/          PlayerController, PlayerAnimator, Lantern
    Interaction/     Interactable, InteractionPrompt, Door
    Memory/          MemoryData, MemoryPlayer, MemoryJournal
    Dialogue/        DialogueData, DialogueRunner, DialogueUI
    Inventory/       ItemData, Inventory, InventoryUI
    UI/              MenuUI, SettingsUI
    Audio/           AudioManager
  003_Prefabs/       Player, Nemu, NPC, Interactable 系
  004_Materials/
  005_Textures/      Characters, Tiles, Backgrounds, UI, Palette
  006_Audio/         BGM, SE, Ambient
  007_Data/          ScriptableObject（会話・記憶・アイテム・章データ）
  008_Fonts/
  099_ImportAssets/  外部アセット
```

### 9.4 主要クラス設計

| クラス | 役割 |
| --- | --- |
| `GameManager` | ゲーム状態（探索中／会話中／記憶再生中／メニュー）の管理。シングルトン |
| `PlayerController` | 左右移動・小走り・入力受付。状態が「探索中」以外なら操作を止める |
| `Interactable`（抽象） | 調べる対象の基底。`Talk` / `Inspect` / `Illuminate` / `UseItem` を派生で実装 |
| `Lantern` | 範囲内の `IIlluminatable` を検出して反応させる。章に応じた能力解放 |
| `MemoryData`（ScriptableObject） | 記憶の ID、タイトル、再生用タイムライン、記憶帳用テキスト・サムネイル |
| `MemoryPlayer` | Timeline を使って記憶シーンを再生。色調切り替え（Volume / マテリアル）も担当 |
| `DialogueData`（ScriptableObject） | 話者・本文・選択肢・実行後のフラグ操作 |
| `DialogueRunner` / `DialogueUI` | 会話の進行と表示（TextMeshPro） |
| `Flags` | 進行フラグ（`Dictionary<string, bool/int>`）。謎の解決状況や会話分岐に使用 |
| `Inventory` / `ItemData` | アイテム所持と使用判定 |
| `SaveSystem` | フラグ・所持品・現在地・記憶帳を JSON で `Application.persistentDataPath` に保存 |
| `AudioManager` | BGM / 環境音 / SE のクロスフェード再生 |

- 会話・記憶・アイテムは **ScriptableObject でデータ化** し、コードを書かずに内容を増やせるようにする。
- 会話量が増えた段階で、外部ツール（Ink / Yarn Spinner）の導入を再検討する。
- 記憶シーンは **Unity Timeline**（導入済み）で演出を組む。

### 9.5 品質目標

- 1080p で 60fps 固定。低スペック PC（内蔵 GPU）でも動作。
- ロード時間：シーン切り替え 1 秒以内（フェード演出で隠す）。
- 主要ロジック（フラグ、インベントリ、セーブ）は Test Framework で EditMode テストを書く。

## 付録 A. 参考にする体験（模倣ではなく雰囲気の参考）

- 『アンリアルライフ』：ドット絵の静かな夜の街、モノに触れて記憶を見るアドベンチャー、余韻のある物語。
- 本作はキャラクター・ストーリー・固有の設定・素材をすべてオリジナルとし、
  既存作品のキャラクター名、シナリオ、グラフィックの流用は行わない。
