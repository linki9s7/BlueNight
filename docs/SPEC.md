## 1. ゲーム概要

| 項目 | 内容 |
| --- | --- |
| タイトル | BlueNight（仮） |
| ジャンル | 2D 見下ろし型・ストーリーアドベンチャー（探索＋光と影の謎解き） |
| 視点 | 斜め見下ろし（3/4 ビュー。建物の正面と屋根、地面が同時に見える角度） |
| プラットフォーム | **Windows（PC）で第 1 章から制作**。Steam 配信・他機種は第 1 章の完成後に検討 |
| プレイ時間 | 本編 3〜4 時間（全 5 章）。最初の目標は第 1 章のみ（20〜30 分） |
| 対象 | 雰囲気のある物語ゲーム、ドット絵、やさしい謎解きが好きな人 |
| エンジン | Unity **2022.3.62f3**（セキュリティ修正版へ更新。既存プロジェクトを利用）＋ URP 2D |
| 言語 | 日本語（将来的に英語） |

### 1.1 コンセプト（一言で）

**「青い夜、持ち主から逃げ出した『影』たちを、ランタンの光で追いつめ、影が抱えていた『言えなかった言葉』を届ける物語」**

### 1.2 体験の柱

1. **静けさと余韻** — 青い夜、街灯、雨上がりの路面の反射。ポストエフェクトで仕上げた、眺めるだけで楽しい画面。
2. **光と影で遊ぶ** — ランタンを動かすだけで、影の長さ・向き・形が変わる。光は影をせき止め、影は影の通り道になる。
3. **やさしい謎解き** — 影は逃げるが、取り逃がしてもペナルティは無し。何度でもすぐやり直せる。
4. **言えなかった言葉** — 影が運んでいた本音を届けるたび、町の人と、主人公自身の気持ちが少しずつほどけていく。

### 1.3 雰囲気の核 ―「BlueNight」の原風景

> 青い夜に大きな満月があって、ハイウェイの上を車で走る二人を、遠目から見た感じ。

このイメージをそのままゲームにするのではなく、**作品全体の空気の基準** として使う。
迷ったときは「この画面・この曲は、あの原風景と同じ温度か？」で判断する。

| 原風景の要素 | 感じ取れるもの | ゲームでの表し方 |
| --- | --- | --- |
| 青い夜 | 静けさ、少しの寂しさ、でも冷たすぎない | 群青を基調にした色設計（7.2）。暗くても「見えない」ほど暗くしない |
| 大きな満月 | 見守られている感じ、どこにいても同じ月が見える | 町のどこからでも月が見える／水たまり・窓・海に月が映る。月明かりが画面全体の青い光（Global Light） |
| ハイウェイ | 遠くへ続く道、流れていく光、ここではないどこか | 町の上を横切る **高架のハイウェイ**。明けない夜でも、遠くを走る車の光だけは流れ続けている（背景の動き） |
| 車で走る二人 | 言葉が少なくても通じ合う距離感、一緒にいる時間の尊さ | ルリとネムの二人旅。会話が無い時間も心地よい間（ま）として演出する |
| 遠目から見た | 主人公たちを少し引いて見守る視点、余韻 | 見下ろし視点そのもの。章の始まり・終わりに、町全体を遠くから映す **遠景カット**（月・ハイウェイ・小さな二人） |

- **ハイウェイの扱い（案）**：町を見下ろす高架として各章の背景にたびたび現れ、
  第 5 章の夜明けの丘から、朝日の中を走っていく車（引っ越していくミオの家の車）が遠くに見える――という形で、
  最後にだけ原風景とそっと重ねる。直接的な説明はしない。

## 2. 世界観・ストーリー（仮）

### 2.1 舞台

- 小さな港町「アオヨ町（仮）」。ある晩から、夜が明けなくなった。
- その晩、町の人々の **影** が一斉に持ち主から離れ、夜の町へ逃げ出した。
- 影は、持ち主が飲み込んだ **「言えなかった言葉」** を抱えて逃げている。
  影が戻らないかぎり持ち主は眠れず、町には朝が来ない。
- 逃げた影は **暗がりの中しか移動できず、光を越えられない**。
- エリア：バス停と商店街 → 雨の路地裏 → 夜の学校 → 灯台と港 → 夜明けの丘（最終章）

### 2.2 あらすじ

明日の朝、親友のミオが町を引っ越していく。
ケンカしたまま「さよなら」も言えずにいる少女・**ルリ**は、眠れずに夜の町へ出る。
ふと足元を見ると、自分の影が無い。

閉まったランプ屋の前で、ルリは古いランタンと、そこに住みついていたしゃべる蛾 **ネム** に出会う。
ネムいわく「影を連れ戻せば、朝は来る」。

ルリは町の人々の影を追いかけ、影が運んでいた言葉を持ち主へ届けていく。
その途中、ルリ自身の影が何度も現れては、からかうように先へ逃げていく。
朝を止めていたのは誰なのか――最後に、ルリは自分の影と向き合うことになる。

> 物語の設計図と台本は **`docs/STORY.md`**、人物のプロフィールは **`docs/CHARACTERS.md`**（v2.0、ユーザーの感想待ち）。
> この夜を止めていたのはルリ自身（「朝なんか、来なければいい」）。朝が来れば、相棒のネム（オオミズアオ）の命も終わる。

### 2.3 テーマ

- 言えなかった本音と、それを言葉にする勇気
- 影＝自分でも見たくない自分。逃げずに向き合うこと
- 明けない夜は「朝が来てほしくない」という誰かの気持ちの象徴
- **さよならを言えなかった別れは、影になる。言えた別れは、約束になる。**（物語が伝えること。`STORY.md` 0.1 節）
- 影は、光があることの証拠（失うのが痛いのは、そこに光があったから）

## 3. ゲームシステム

### 3.1 基本ループ

```
エリアを探索する
  → 人と話す／影を失った人を見つける
  → 逃げた影を見つけ、ランタンと町の光で逃げ道をふさぎ、追いつめる
  → 捕まえた影から「言えなかった言葉」を聞く
  → 言葉を持ち主に届け、影を返す（小さなご褒美演出：影が戻り、その人が眠りにつく）
  → 新しい場所が開く／物語が進む
```

### 3.2 移動・探索

- **WASD または矢印キーで上下左右に移動**（斜めも可の 8 方向移動。斜めでも速さは同じになるよう補正）。
  ゲームパッドは左スティック／十字キー。
- 歩き／小走りの 2 段階。ジャンプは無し（落ち着いた操作感を優先）。
- **キャラクターの向きは 4 方向（上・下・左・右）に決定。** 斜め移動中は左右の向きを優先して表示。
  - 理由：8 方向に比べて絵の枚数が約半分で済み、その分を表情・仕草・環境アニメーションに回せる。
    16×32 px 程度のキャラでは斜め向きの差が出にくく、見下ろし型ドット絵の定番でもある。
  - 移動は 8 方向のままなので、操作の気持ちよさは損なわない。
- 段差・柵・水路などは通れない。扉・階段は触れるか「調べる」で移動。
- 部屋（マップ）は画面より広く、カメラがルリを追従して上下左右にスクロール。
  部屋の端ではカメラが止まる（マップ外は映さない）。
- 調べられる対象に近づくと、頭上に小さなアイコン（💬会話／🔍調べる／🏮ランタン）を表示。
  向いている方向の、いちばん近い対象が選ばれる。

### 3.3 光と影（コアメカニクス）

#### 影の基本ルール（見下ろし視点）
- モノの影は、光源と **反対の方向** に地面へ伸びる。
- 影の長さは光源からの距離で決まる（**光から遠いほど長い**）。複数の光があれば影も複数できる。
- 見下ろし視点なので、影の向き・長さの変化がプレイヤーから常に見えるようにする。

#### ランタン
- ルリが持ち歩く光源。持っている間は光がルリに追従する。
- **掛ける**：町にある「ランタン掛け（フック）」にランタンを掛けると、その位置に光を固定できる。
  掛けたランタンの位置で、周囲のモノの影の向きと長さが変わる。
- **置く**：章が進むと、フックが無い場所の地面にも置けるようになる。
- **街灯・窓明かり**：スイッチや窓を調べて点灯／消灯できるものがある。

#### 逃げた影
- 影は **暗い場所だけ** を移動し、光の当たった場所には入れない。
- 影の通り道はモノの影ともつながる。光の当て方で、塀やベンチの影を伸ばして **影の橋** をつくると、
  影は明るい場所の上を、その影づたいに渡って移動できる。
- 影はルリから逃げるように動く。光と影の通り道を組み替えて、**行き止まりに追いつめる** と捕まえられる。
- 取り逃がしても、少し待つと元の場所に戻ってくる（ゲームオーバー無し・焦らせない）。

#### 影の言葉
- 捕まえた影は、持ち主が言えなかった言葉をぽつりと話す（短い影絵の演出）。
- 聞いた言葉は **「ことば帳」** に記録され、いつでも見返せる。
- 持ち主に影を返すとき、言葉をどう伝えるかを選ぶ場面がある（分岐はせず、反応が変わる程度）。

#### ランタンの成長（章が進むと解放）
| 章 | 能力 | 内容 |
| --- | --- | --- |
| 1 | 持つ・掛ける | 光を運ぶ／フックに固定する |
| 2 | 置く | フックの無い地面にもランタンを置ける |
| 3 | 青い炎 | 青い光で照らした影は **実体化** し、ルリが上を歩ける・押せるようになる（影の足場で水路や崩れた床を渡る） |
| 4 | 光を投げる | 光の玉を遠くへ投げ、離れた場所を一時的に照らす |

### 3.4 謎解き

- 原則として **「光を置く場所を考え、影の形と通り道を組み替える」** 形式。例：
  - 街灯を消し、ランタンを別のフックに掛け替えて、影の逃げ道を一つずつふさぐ
  - ランタンを自販機から離れたフックに掛けて自販機の影を長く伸ばし、向かいの塀の影とつなげて影の橋をつくる
  - 鉢植えや看板を押して動かし、床のタイル模様に影の形をぴったり重ねると扉が開く（影合わせパズル）
  - 青い炎で自転車の影を実体化させ、水路の上を渡る
- アイテムは少数（同時所持 8 個まで）。「使う」は対象の前でアイテムを選ぶだけ。組み合わせは無し。
- 詰まり対策：ネムに話しかけると段階的なヒント（3 段階）。部屋ごとに「光をリセット」できる。

### 3.5 会話

- 画面下部のウィンドウに 1 文字ずつ表示。顔グラフィックは小さめ（48×48 px）。
  v0.19：顔はウィンドウの左に出し、名前と本文はその右から書く（ユーザーの希望：名前だけでは一目で分かりにくい。参考『アンリアルライフ』）。
  セリフごとに表情を選ぶ（`BlueNightSetup.Chapter1Story` の `Ru("…", "sad")` など）。序章のルリの顔は服（パジャマ → マフラー無し → ふだん）に合わせる。
- 選択肢は少数で、物語の分岐は無し（一本道）。会話の雰囲気が変わる程度。
- 一部の会話はウィンドウを出さず、キャラの頭上に吹き出しで表示（町の生活音的なつぶやき）。
- 影のセリフは白抜きの文字＋揺れる表示で、人のセリフと区別する。

### 3.6 収集要素（任意）

- 町中に小さな **「落とし影」**（猫や鳥、モノの影など、本筋に関係ない小さな影）が隠れている。
  捕まえると、その影が抱えていた小さなひとことがことば帳に増える。
- 全部集めるとエンディング後に短い追加シーン。

### 3.7 セーブ

- オートセーブ（エリア移動時・影を返したとき）＋ メニューから手動セーブ（3 スロット）。

## 7. アート仕様（ドット絵）

### 7.1 解像度

| 項目 | 値（仮） |
| --- | --- |
| 内部解像度 | **480 × 270 px（決定）**（16:9。1920×1080 / 3840×2160 では整数倍 ×4 / ×8 でぴったり表示。1280×720 など割り切れない解像度では ×2 で表示し周囲に黒帯） |
| Pixels Per Unit | 16 |
| タイルサイズ | 16 × 16 px |
| 主人公のサイズ | 約 16 × 32 px（3/4 ビューの頭身。足元 16×16 を当たり判定にする） |
| 顔グラフィック | 48 × 48 px |
| フォント | 日本語ドットフォント（候補：DotGothic16〈OFL〉、PixelMplus〈M+ ライセンス〉）※ライセンス確認の上採用 |

### 7.2 カラー・雰囲気

- 基調色は **深い青〜群青〜紺**。差し色は街灯・窓明かり・ランタンの **暖色（橙・黄）**。
- 普通の影は紺色。**逃げた影は真っ黒＋輪郭がかすかに水色に光る**ことで、ひと目で区別できるようにする。
- 青い炎で実体化した影は、半透明の青い板のような質感。
- **月の光**：画面全体を照らす青白い光は「月明かり」として扱う（月明かりは逃げた影をせき止めない、という町のルール）。
  月は水たまり・窓ガラス・海面に映り込みとして描き、どの章でも「同じ大きな満月」が見えるようにする。
- **遠くの光の流れ**：高架のハイウェイを走る車のヘッドライト／テールランプの光点が、ゆっくり流れ続ける背景アニメーション。
- パレットは 32〜48 色程度に制限して統一感を出す（自作パレットを `Assets/005_Textures/Palette.png` に用意）。

### 7.3 マップの描き方

- Tilemap を層に分けて描く：**地面 → 地面の装飾（白線・水たまり） → 影 → 壁・建物の下部 → キャラクター／モノ → 建物の上部・屋根・木の葉（手前）**。
- キャラクターとモノは **足元の Y 座標で前後を自動で並べ替える**（建物の裏に回ると隠れる）。
- 屋根のある場所に入ると、屋根がふっと透けて中が見える。

### 7.4 アニメーション

| 対象 | パターン |
| --- | --- |
| ルリ（4 方向それぞれ） | 待機 4f、歩き 6f、小走り 6f、調べる 3f、ランタンを掛ける・置く 5f（試作版は待機 4f・歩き 4f） |
| ネム | 羽ばたき 4f（常時ふわふわ追従。暗い部屋ではルリの背中に隠れる） |
| 逃げた影（4 方向） | 待機 4f、移動 6f、驚く 3f、捕まる 6f（持ち主ごとに輪郭が異なる） |
| ルリの影 | ルリと同じ骨格で、動きだけ大げさ・いたずらっぽく |
| NPC | 下向き中心の待機 2〜4f＋固有の仕草 1 種（影が無い状態／戻った状態の 2 種） |
| 環境 | 雨、水たまりの波紋、街灯の明滅、湯気、蛾の群れ、風に揺れる洗濯物 など |

### 7.5 ライティングと影の表現

- URP 2D ライトを使用。全体は暗めの Global Light（青）＋ 街灯・窓・ランタンの Point Light（暖色）。
- **影はドット感を守るため、Unity 標準の Shadow Caster 2D（ソフトな影）ではなく、専用の「影タイルマップ」で描く。**
  影グリッド（9.3）の計算結果をそのままタイルとして置き、Rule Tile（隣接に応じて形が変わるタイル）でふちをドット絵らしく整える。
- ライトの影響はシンプルに（ノーマルマップは使わない予定）。

### 7.6 ポストエフェクト（画面効果）

ドット絵の「くっきり感」は保ったまま、光のにじみ・空気感・色味で **映画のような夜** に仕上げる。

#### 常時かける効果
| 効果 | 目的・設定の方向性 |
| --- | --- |
| ブルーム | 街灯・窓・ランタン・逃げた影の輪郭の光を、ふんわりにじませる。しきい値高めで、光るものだけに効かせる |
| カラーグレーディング | 暗部は青〜紺、明部は暖色に寄せる（スプリットトーン）。エリアごとに LUT（色の変換表）を用意して色味を変える |
| ビネット | 画面の四隅をほんのり暗くして、視線を中央へ |
| フィルムグレイン | ごく弱く。夜のざらっとした空気感を出す |
| 色収差 | ごく弱く、画面の端だけ。影の場面で少し強める |

#### 演出として一時的にかける効果
| 場面 | 効果 |
| --- | --- |
| 影が近くにいる | 画面の端がわずかにゆらぐ（ディストーション）＋彩度を少し下げる |
| 影を捕まえた瞬間 | 一瞬だけ色を反転したようなフラッシュ → 静かにモノトーンへ |
| 影の言葉の演出 | ほぼモノクロ＋青だけ残す、走査線のようなゆらぎ |
| 屋内・路地 | ビネットを強め、グレーディングを暖色寄りに |
| 雨 | 画面全体にうっすら雨のにじみ（レンズについた水滴風）、ブルームを強める |
| 夜明け（最終章） | 青から朝焼けの色へ、数十秒かけてゆっくりグレーディングを移す |

#### 画面の空気をつくる重ね絵（2D レイヤー）
- ゆっくり流れる **霧**（ノイズテクスチャの半透明レイヤー）。
- 街灯の下に漂う **光の粒・ほこり・羽虫**（パーティクル）。
- 窓や街灯から差し込む **光の筋**（加算の半透明スプライト）。

#### 実装・運用の方針
- URP の **Volume（ポストプロセスの設定セット）** をエリアごとに用意し、エリア移動時は 1〜2 秒かけて切り替える（パチッと変えない）。
- 演出用の効果は `PostFXController` からコードで強さを補間して出し入れする。
- **描画の順番**：色を変える効果（グレーディング）はドット絵の解像度（480×270）側で、にじむ効果（ブルーム・グレイン）は拡大後の画面解像度側でかけるのが理想。
  **M0 で URP 14 のソースを確認した結果**：Pixel Perfect Camera の Upscale Render Texture を使うと、
  ポストエフェクトは **すべて 480×270 のまま処理され、そのあと拡大される**（ブルームやグレインも低解像度になる）。
  **v0.11 で決定：この標準構成のままにする。** すべての効果が 480×270 のドットの格子の上でかかるので、
  ドットの大きさが混ざらない（ミクセルを作らない、7.8）。高解像度側でブルーム等をかける 2 段カメラ構成は採らない。
  ブルームやグレインが粗く見える場合は、強さ・しきい値・グレインの粒の大きさ（1 ドット単位）で調整する。
- 設定画面で **画面効果の品質（高／低）** と、**グレイン・色収差・画面のゆらぎを個別にオフ** にできるようにする（酔いやすい人・低スペック PC への配慮）。

### 7.8 ドット絵の制作手順（Claude が制作）

```
① 設計     パレット（32〜48 色）、サイズ規格、ライティングの向き（光は左上の月から）を決める
② 制作     Python スクリプトで 1 ピクセルずつ PNG を作る
           ・キャラ／モノ：ドットを文字の図（ピクセルマップ）として書き起こす
           ・タイル／背景：パーツの組み合わせと規則で生成（レンガ・石畳・瓦など）
③ 確認     拡大プレビュー画像を書き出して Claude 自身が目で見て直す
④ 試遊確認 Unity に取り込み、実際の画面（ライト・ポストエフェクト込み）で見え方を確認
⑤ フィードバック  あなたに見てもらい、感想をもとに直す
⑥ 書き出し スプライトシート（アニメーションは横並び）＋取り込み設定（Point / 圧縮なし / PPU 16 / 足元ピボット）
```

人物（v0.16〜）は輪郭線を引かず、明暗と左上の縁の月明かりで描く（`Tools/Art/chara.py`、STYLE.md 3 章）。リデザインの経緯と案は `Tools/Art/art_plan.md`。

- **ツール**：Python（Pillow）。スクリプトとピクセルマップを `Tools/Art/` に置き、色やサイズを後から一括で直せるようにする。
- **作る順番**：パレット → 地面・壁のタイル → ルリ（4 方向・歩き）→ ネム → ランタン・街灯 → 第 1 章の建物・小物 → NPC → 逃げた影 → UI・顔グラフィック。
- **品質の目安**：まず仮素材（形と色だけ）で第 1 章を遊べる状態にし、M2 で本番品質に描き込む。
- **描き方のルール（v0.11、詳しくは `Tools/Art/STYLE.md`）**
  - 描く前に参考資料（実物の写真・ドット絵の教本・同じサイズのゲーム）を調べる。
  - マップごとに色数を絞った専用パレットを持つ（`palette.py` の `MAP_PALETTES`）。
  - 1 ドットの輪郭線をつけ、`clean_corners` で段差のダブりを取る。ダブりは絵ごとに数えて記録する（目安 10 以下、今は全部 0）。
  - 避けること：ダブり、バンディング（輪郭の内側 1 列の影も）、ピローシェーディング、浮いたアンチエイリアス、網点の使いすぎ。
  - **光はどの向きの絵でも画面の左上から。** 左向きの絵は形だけ反転して陰影を描き直し、ゲームでも flipX で反転しない。
  - **ミクセルを作らない**：1 ドット＝1 ドット。画面・ライト・ポストエフェクト・会話の文字まで、すべて 480×270 の格子の整数倍。
  - 今までの絵の調子に合わせる：少ない色数、くっきりした 1 ドットの輪郭、平らな塗り＋小さな模様。
  - 点検：`python3 Tools/Art/pixel_check.py` → `Tools/Art/report/pixel_report.md`。
- **注意点**：キャラの表情やアニメーションの「生きている感じ」は手描きのドット絵職人に比べて最も難しい部分。
  動きの少ない落ち着いた作風（1.3）を活かし、少ないコマ数でも仕草で感情が伝わるよう、確認と修正を重ねる。

## 8. サウンド仕様

### 8.1 構成

| 種類 | 方針 |
| --- | --- |
| BGM | ピアノ・ローファイ・アンビエント中心。エリアごとに 1 曲＋影を追う場面＋影の言葉の場面＋テーマ曲。全 8〜10 曲 |
| 環境音 | 雨、遠くの車、虫の声、波、電灯のジジッという音。BGM と別トラックで常に流す |
| SE | 足音（地面の材質別）、ランタンの着脱、街灯の点灯／消灯、影の気配・逃走・捕獲、決定・キャンセル、会話の文字送り |
| ボイス | 無し（文字送り音で代用。影のセリフは逆再生風の別の音） |

### 8.2 音楽の品質方針（「AI っぽさ」の少ない、手ざわりのある音）

- **作曲は Claude が担当する。** ただし、テキストから曲の音声を丸ごと生成するタイプの音楽生成 AI は使わない。
  メロディ・和音・伴奏・強弱を **楽譜（MIDI）として 1 音ずつ意図をもって書き**、実在の楽器を録音した音源で鳴らす（制作手順は 8.4）。
  「なんとなくそれっぽい」曲ではなく、場面の意味から逆算した曲にする。
- **テーマ（モチーフ）でつなぐ**：「ルリのテーマ」「影のテーマ」など短いメロディを決め、各曲にアレンジして織り込む。
  曲同士がつながって聞こえることで、作品としての一貫性を出す。
- **生音の質感**：ピアノは実際のグランドピアノを録音した音源を使い、ペダルの音・鍵盤のノイズ・部屋の響きをあえて残す。
  チェロ、アコースティックギター、グロッケンなども録音ベースの音源を使う。テープの揺れや軽いノイズで「夜の録音」らしさを出す。
- **人が弾いたような演奏**：打ち込みっぽさを消すため、強弱（ベロシティ）を一音ずつ変え、
  タイミングをわずかに揺らし、フレーズの終わりで少しテンポを緩める。ペダルの踏み替えも楽譜に書く。
- **展開と余白**：同じフレーズを機械的に繰り返さない。音数を減らした静かな部分、間（ま）を大事にする。
- **ループの丁寧さ**：イントロ付きループ（イントロは 1 回だけ、以降はループ部分を繰り返す）。ループのつなぎ目が分からないよう、残響まで含めて処理する。
- **ミックスの目安**：曲ごとの音量差が出ないよう、ラウドネスを揃える（目安：-16 LUFS、ピーク -1 dBTP）。
- 効果音も既成素材の使い回しは最小限にし、足音・ランタンの金具の音などは録音（フォーリー）も検討する。

### 8.3 音楽の切り替え（自然なフェード）

| 場面 | 切り替え方 |
| --- | --- |
| エリア移動 | 今の曲を 2〜3 秒でフェードアウト → 0.5 秒ほど間を置いて次の曲を 2 秒でフェードイン。似た雰囲気の曲同士はクロスフェード |
| 影を追う場面に入る／出る | **曲は切り替えず、楽器の層を足し引きする**（同じテンポ・同じキーで作った重ね用トラックを 1〜2 秒で出し入れ） |
| 影を捕まえた | 短い効果音的なフレーズ（スティンガー）を鳴らし、影の言葉の曲へ 3〜4 秒でクロスフェード |
| 会話中 | BGM を約 -4 dB 下げる（0.5 秒かけて）。会話が終わったら 1 秒で戻す |
| 屋内に入る | 環境音にこもり（ローパス）をかけ、音量を下げる。外に出ると戻す |
| メニューを開く | 曲は止めずに、こもらせて音量を下げる |
| 夜明け（最終章） | 環境音を数十秒かけて夜の音（虫・波）から朝の音（鳥）へ移し、テーマ曲へ |

- フェードは **人の耳に自然に聞こえるカーブ（等パワーのクロスフェード）** を使い、直線的な音量変化は使わない。
- 曲の切り替えは可能なかぎり **小節の頭** に合わせる（リズムが途中で途切れないように）。
- 一時停止中やスロー演出中もフェードが止まらないよう、ゲーム内時間とは別の時間で処理する。

### 8.4 音楽の制作手順（Claude 自作）

```
① 曲の設計書   場面・感情・テンポ・キー・使うモチーフ・楽器・ループ構成を 1 曲 1 枚で書く
② 作曲         Python スクリプトで MIDI を書き出す（メロディ・和音・伴奏・強弱・ペダル）
③ 演奏の味付け  ベロシティの揺らぎ、タイミングの揺らぎ、フレーズ末のテンポの緩み
④ 音にする     録音ベースの楽器音源（SoundFont / SFZ）で WAV に書き出す
⑤ 仕上げ       リバーブ、テープ風の揺れ・ノイズ、EQ、ラウドネス調整（-16 LUFS / -1 dBTP）
⑥ 書き出し     OGG に変換し、ループ開始・終了位置を曲データ（ScriptableObject）に記録
⑦ 試聴と修正   あなたに聴いてもらい、感想をもとに①〜⑥を直す
```

- **楽器音源**：
  - **楽器**：MuseScore General SoundFont（MIT）。録音素材の配布サイトが作業環境から使えないため。
  - Salamander Grand Piano V3 も試したが、リズムに合わせて低音が「ドシン」と響くのが不快との判断で不採用（v0.9）。
    ほかの楽器を差し替える場合も、聴いてもらってから決める。
  - **環境音**：商用利用できる録音（CC0／CC BY）を素材にして組み立てる（8.6）。
  - クレジットとライセンスは `docs/CREDITS.md` にまとめる。
- **ツール**：Python（MIDI 作成）、FluidSynth または sfizz（音源で WAV 化）、ffmpeg（変換）、
  ラウドネス測定ツール。いずれもリポジトリの `Tools/Music/` に手順をまとめ、誰でも同じ曲を再生成できるようにする。
- **楽譜（MIDI）とスクリプトもリポジトリに入れる**。将来、別の音源や DAW で鳴らし直して音質を上げることもできる。
- **注意点**：Claude は書き出した音を自分の耳で聴けない。音量バランスや響きの最終判断は、⑦で **あなたが聴いた感想** を頼りに直していく。
  そのため、まず短いスケッチ（30 秒程度）で方向性を確認してから、1 曲を仕上げる進め方にする。
- 効果音（SE）も同じ手順で作れるものは自作し、足音や環境音など録音が必要なものは、商用利用できるフリー素材から選ぶ。

### 8.5 聴き心地のルールと制作済みの曲（v0.8）

- **帯域**：話し声の帯域（500 Hz〜2 kHz）を少し下げ、40 Hz 以下と耳に刺さる高音を落とす。
- **音量の安定**：ゆるいコンプレッサーで急な音量変化を抑え、全曲 −16 LUFS にそろえる。環境音は −26 LUFS。
- **環境音**：主役を 1 つ決め、背景は主役より 10〜16 dB 小さく重ねる。ノイズは隠し味程度。左右に散らし、リバーブは使わない（詳細は `bgm_plan.md`）。
- **旋律は控えめに**：和音の循環が主役。旋律をはっきり聴かせるのはタイトル曲だけ。
- **テンポ**：探索曲は BPM 60〜80（心拍に近い速さ）。影を追う場面だけ 100。
- **アタック**：強いドラムは使わず、ブラシ・リム・シェイカー中心。
- **音色**：こもったピアノ、ローファイなエレピ、ナイロンギター、薄いパッド。
- 曲目・調・楽器・長さの一覧は `Tools/Music/designs/bgm_plan.md`。BGM 8 曲（うち影を追う場面は 3 レイヤー）、スティンガー 1、環境音 4（雨・波・遠いハイウェイ・虫）。
- ゲーム内の再生（前奏→ループの予約再生、レイヤーの音量の上げ下げ）は、Unity で動作確認できる環境で実装する。

### 8.7 効果音（v0.10）

- 足音（石畳・濡れた路面・木の床、各 6 パターン）、ランタンの着脱、街灯の点灯・消灯、影の気配・逃走・捕獲、
  UI（決定・キャンセル・文字送り・メニュー開閉・カーソル・ことば帳に記録）を制作済み。
- 現実の物の音は録音（パブリックドメイン・CC0・CC BY）を材料に組み立て、UI 音は uisfx（CC0）を使う。
- 一覧・作り方・Unity での鳴らし方は `Tools/Music/designs/se_plan.md`。

### 8.8 Unity での再生（v0.14）

| 係 | 内容 |
| --- | --- |
| 音のデータ（`AudioLibrary`） | `Tools/Music` の manifest（JSON）から、メニュー **BlueNight > 5. 音のデータを作成** で作る（シーンを作るときにも自動で作り直す） |
| BGM（`MusicDirector`） | 前奏 → ループを `PlayScheduled` ですき間なくつなぐ。曲の入れ替えは等パワーのフェード（エリア移動は「消す → 0.5 秒の間 → 入れる」、似た曲はクロスフェード）。層のある曲は全部の層を同時に鳴らし、層ごとに出し入れする。会話中は -4 dB（0.5 秒で下げ、1 秒で戻す）。ゲームの一時停止に左右されない時間で動く |
| 影を追う場面（`ChaseMusic`） | 影に 9 マスまで近づくと「影を追う」（土台の層）へクロスフェード、5 マスで太鼓、2.6 マスで弦。離れると町の曲へ。捕まえたらスティンガー＋「影の言葉」へ 3.5 秒のクロスフェード、会話のあと町の曲へ。影の近くでは「影の気配」がかすかに鳴る |
| 環境音（`AmbiencePlayer`） | 何種類でも重ねて、ゆっくり出し入れ。屋内（`AreaZone`）では、こもらせて（ローパス 1200 Hz）-8 dB |
| 効果音（`SoundEffects`） | グループ名で鳴らす。前回と違うファイルを選び、音の高さをほんの少しゆらす。足音は床（`AreaZone`：石・木・濡れた路面）と歩き・小走りの歩幅で鳴らし分ける。ランタンの着脱、影がすっと逃げる・捕まえた、会話の文字送り（2 文字に 1 回）・決定 |
| 音量 | BGM・環境音・効果音ごとに `VolumeScale`（設定画面で使う）。AudioMixer は使わず、コードで音量とこもりを決める |

### 8.6 環境音の録音素材

- **現在**：雨・波・遠くのハイウェイは、商用利用できる録音（雨：CC BY 3.0、川・滝：CC0）を素材にして組み立てている
  （`Tools/Music/sources/`）。**雨と波は今の版で確定**（ユーザーの判断）。
- 0 A.D.（CC BY-SA 3.0）の素材は使わない（ユーザーの判断）。
- **TODO（ユーザーの依頼）：虫の声（`ambient_crickets` の主役ともう 1 匹・遠くの合唱）は今は合成。
  録音素材が手に入る環境（ローカル）に切り替えたら、商用利用できる録音に差し替える。**
- **ローカル環境で入手できるもの**：配布サイトにつながる環境では、次のような商用利用できる録音素材で、さらに質を上げられる。

| 入手先 | 条件 | 向いている音 |
| --- | --- | --- |
| Sonniss「GDC Game Audio Bundle」（無料） | ロイヤリティフリー・商用可・表記不要（素材そのものの再配布・販売は不可）。利用前に同梱の規約を確認 | 雨・波・夜の虫・遠くの交通音など、プロが録音した環境音 |

## 9. 技術仕様

### 9.1 現在のプロジェクト状態

- 作成時は Unity 2022.3.34f1、URP 14.0.11（**3D 用テンプレート**：Plane / Directional Light のみのシーン）。
- セキュリティ警告への対応として **Unity 2022.3.62f3 に更新**。URP はエディタに合わせたバージョンに自動で上がる。
- 入力は旧 Input Manager（`activeInputHandler: 0`）。
- スクリプトはまだ無し。

### 9.2 必要な変更（M0 で実施）

1. URP を **2D Renderer**（`Renderer2D` アセット）に切り替え、URP アセットに設定する。ポストプロセスを有効化。
2. パッケージ追加：
   - `com.unity.2d.sprite`、`com.unity.2d.tilemap`
   - `com.unity.inputsystem`（WASD／矢印キー／ゲームパッドの同時対応・キー設定変更のため）
   - ※ `com.unity.2d.tilemap.extras`（Rule Tile）は影タイルを作る M1 で追加する。
   - ※ カメラ追従は、ドット単位の位置合わせを確実にするため自前の `CameraFollow2D` で行い、Cinemachine は見送る。
3. Main Camera に **Pixel Perfect Camera**（480×270, PPU 16）を設定。ポストエフェクトとの組み合わせを検証（7.6）。
4. 前後の並び替え：Renderer2D の Transparency Sort を **Y 軸基準**（Custom Axis = (0, 1, 0)）に設定。
5. スプライト取り込み設定の標準化：Filter Mode = Point、Compression = None、PPU = 16、Pivot = 足元。
6. 不要な 3D 要素（Plane、Ground.mat、TutorialInfo）を整理。

### 9.3 光と影のロジック（影グリッド）

- 各部屋を **16px 単位の 2D グリッド**（地面のマス目）として扱い、マスごとに「明るい／暗い／影の橋／実体化した影」を計算する。
  - 光源（ランタン・街灯・窓）は半径と遮蔽物から、照らすマスを決める。
  - 影を落とすモノ（`ShadowCaster`）は、光源と反対方向に、距離に応じた長さで影のマスを伸ばす。
- 逃げた影はこのグリッド上の **暗いマスだけ** を経路探索（BFS、上下左右 4 方向）して、ルリから遠ざかるように動く。
  - 逃げ方：「ルリより先にたどり着ける暗いマス」だけを通って行ける範囲で、ルリからいちばん遠いマスを目指す。
    1 歩先だけを見る単純な逃げ方だと、幅 2 マスの路地でルリの横に並んでしまうため（M1 のテストで判明）。
  - その結果、輪になった路地では反対側へ回り込み続け、光で輪を切ると行き止まりへ逃げ込む（＝追いつめられる）。
  - 影の速さはルリの小走りより少し速い（6.5 マス/秒）。輪のままでは捕まらない。
- 光や物の配置が変わるたびにグリッドを再計算する（1 部屋あたり最大 60×34 マス程度を想定。変化した光源の周りだけ再計算して負荷を抑える）。
- 見た目の影タイルも同じグリッド結果から置くため、**「見た目の影」と「判定」が必ず一致** する。
- 謎の設計・デバッグ用に、エディタ上でグリッドの状態を色分け表示するギズモを用意する。

### 9.6 品質目標

- 1080p で 60fps 固定（ポストエフェクト「高」設定時）。低スペック PC（内蔵 GPU）でも「低」設定で 60fps。
- ロード時間：シーン切り替え 1 秒以内（フェード演出で隠す）。
- 斜め移動やカメラのスクロールでドット絵がガタつかないこと（ピクセル単位への位置合わせを確認）。
- 主要ロジック（影グリッドの計算、影の経路探索、フラグ、インベントリ、セーブ）は Test Framework で EditMode テストを書く。

## 付録 A. 参考作品と差別化

| 観点 | 『アンリアルライフ』（雰囲気の参考） | BlueNight（本作） |
| --- | --- | --- |
| 視点 | 横から見たサイドビュー | 斜め見下ろし（3/4 ビュー）で、上下左右に自由に歩く |
| 主人公 | 記憶を失った少女 | 記憶はある。「言えない」ことを抱えた少女 |
| コアメカニクス | モノに触れて、その記憶を見る | 光の置き場所で影を操り、逃げた影を追いつめる |
| 物語の軸 | 失った記憶と約束をたどる | 町じゅうの「言えなかった言葉」を届け、最後に自分の本音と向き合う |
| 謎の解き方 | 記憶で得た情報を使う | 光と影の配置そのものを組み替える（空間パズル） |

- 影を使った謎解きは他作品（例：『Contrast』『Schim』）にもあるため、
  **「光が影をせき止める追いつめパズル」＋「影が持ち主の本音を運んでいる」** という組み合わせで差別化する。
- 本作はキャラクター・ストーリー・固有の設定・素材をすべてオリジナルとし、
  既存作品のキャラクター名、シナリオ、グラフィックの流用は行わない。
