# BlueNight ゲーム仕様書（ドラフト v0.2）

> 本書は「BlueNight」の初期仕様書です。『アンリアルライフ（UNREAL LIFE）』のような
> **ドット絵 × 静かな夜の街 × 余韻のある物語** という雰囲気をイメージしていますが、
> キャラクター・世界観・ストーリー・メカニクスはすべてオリジナルとして設計します。
> 「仮」と書いた項目は、今後の相談で決める前提の値です。
>
> **v0.2 の変更点**：オリジナリティを高めるため、コアを「モノの記憶をたどる／失くした約束を思い出す」から
> **「逃げ出した影を光で追いつめ、影が運ぶ『言えなかった言葉』を届ける」** に変更。
> 主人公の記憶喪失設定も廃止（詳細は付録 A）。

## 1. ゲーム概要

| 項目 | 内容 |
| --- | --- |
| タイトル | BlueNight（仮） |
| ジャンル | 2D 横スクロール・ストーリーアドベンチャー（探索＋光と影の謎解き） |
| 視点 | サイドビュー（横から見た断面的な街並み） |
| プラットフォーム | Windows（Steam 想定）。将来的に Switch／スマホも検討 |
| プレイ時間 | 本編 3〜4 時間（全 5 章）。最初の目標は第 1 章のみ（20〜30 分） |
| 対象 | 雰囲気のある物語ゲーム、ドット絵、やさしい謎解きが好きな人 |
| エンジン | Unity 2022.3.34f1（既存プロジェクトを利用）＋ URP 2D |
| 言語 | 日本語（将来的に英語） |

### 1.1 コンセプト（一言で）

**「青い夜、持ち主から逃げ出した『影』たちを、ランタンの光で追いつめ、影が抱えていた『言えなかった言葉』を届ける物語」**

### 1.2 体験の柱

1. **静けさと余韻** — 青い夜、街灯、雨上がりの路面の反射。急かされない、眺めるだけで楽しい画面。
2. **光と影で遊ぶ** — ランタンを動かすだけで、影の長さ・向き・形が変わる。光は影をせき止め、影は影の通り道になる。
3. **やさしい謎解き** — 影は逃げるが、取り逃がしてもペナルティは無し。何度でもすぐやり直せる。
4. **言えなかった言葉** — 影が運んでいた本音を届けるたび、町の人と、主人公自身の気持ちが少しずつほどけていく。

## 2. 世界観・ストーリー（仮）

### 2.1 舞台

- 小さな港町「アオヨ町（仮）」。ある晩から、夜が明けなくなった。
- その晩、町の人々の **影** が一斉に持ち主から離れ、夜の町へ逃げ出した。
- 影は、持ち主が飲み込んだ **「言えなかった言葉」** を抱えて逃げている。
  影が戻らないかぎり持ち主は眠れず、町には朝が来ない。
- 逃げた影は **暗がりの中しか移動できず、光を越えられない**。
- エリア：バス停と商店街 → 雨の路地裏 → 夜の学校 → 灯台と港 → 夜明けの丘（最終章）

### 2.2 あらすじ

明日の朝、親友のミオが町を引っ越していく。
ケンカしたまま「さよなら」も言えずにいる少女・**ルリ**は、眠れずに夜の町へ出る。
ふと足元を見ると、自分の影が無い。

閉まったランプ屋の前で、ルリは古いランタンと、そこに住みついていたしゃべる蛾 **ネム** に出会う。
ネムいわく「影を連れ戻せば、朝は来る」。

ルリは町の人々の影を追いかけ、影が運んでいた言葉を持ち主へ届けていく。
その途中、ルリ自身の影が何度も現れては、からかうように先へ逃げていく。
朝を止めていたのは誰なのか――最後に、ルリは自分の影と向き合うことになる。

### 2.3 テーマ

- 言えなかった本音と、それを言葉にする勇気
- 影＝自分でも見たくない自分。逃げずに向き合うこと
- 明けない夜は「朝が来てほしくない」という誰かの気持ちの象徴

### 2.4 主要キャラクター

| 名前 | 役割 | 特徴 |
| --- | --- | --- |
| ルリ | 主人公 | 14 歳の少女。青いマフラー。口下手で、大事なことほど言えない。自分の影が無い。 |
| ネム | 相棒 | ランタンに住みついていた手のひらサイズの蛾。おしゃべりでツッコミ役。光が大好きで暗がりが苦手。ヒント役も兼ねる。 |
| ルリの影 | もう一人の主人公 | ルリから逃げた影。いたずら好きで、ルリが言えないことを平気で口にする。章の終わりごとに現れる。 |
| ランプ屋の主人 | 導き手 | 影が逃げたことに唯一気づいている老人。ランタンの使い方と、影の性質を教えてくれる。 |
| 町の人々 | 各章の依頼者 | 商店のおばあさん、部活に悩む学生、灯台守など。それぞれ一つの「言えなかった言葉」を影に持ち逃げされている。 |
| ミオ | 親友 | 引っ越していく親友。物語の大半は不在で、最終章の夜明けに登場する。 |

## 3. ゲームシステム

### 3.1 基本ループ

```
エリアを探索する
  → 人と話す／影を失った人を見つける
  → 逃げた影を見つけ、ランタンと町の光で逃げ道をふさぎ、追いつめる
  → 捕まえた影から「言えなかった言葉」を聞く
  → 言葉を持ち主に届け、影を返す（小さなご褒美演出：影が戻り、その人が眠りにつく）
  → 新しい場所が開く／物語が進む
```

### 3.2 移動・探索

- 左右移動（歩き／小走り）。ジャンプは無し（落ち着いた操作感を優先）。
- 扉・階段・はしごは「調べる」で移動。画面端で隣の画面へ切り替え（1 画面〜横 3 画面程度のスクロール部屋）。
- 調べられる対象に近づくと、頭上に小さなアイコン（💬会話／🔍調べる／🏮ランタン）を表示。

### 3.3 光と影（コアメカニクス）

#### ランタン
- ルリが持ち歩く光源。持っている間は光がルリに追従する。
- **掛ける**：町にある「ランタン掛け（フック）」にランタンを掛けると、その位置に光を固定できる。
  掛けたランタンの位置で、周囲のモノの影の向きと長さが変わる。
- **街灯・窓明かり**：スイッチや窓を調べて点灯／消灯できるものがある。

#### 逃げた影
- 影は **暗い場所だけ** を移動し、光の当たった場所には入れない。
- 影の通り道はモノの影ともつながる。光の当て方で、塀やベンチの影を伸ばして **影の橋** をつくると、
  影はそこを渡って移動できる。
- 影はルリから逃げるように動く。光と影の通り道を組み替えて、**行き止まりに追いつめる** と捕まえられる。
- 取り逃がしても、少し待つと元の場所に戻ってくる（ゲームオーバー無し・焦らせない）。

#### 影の言葉
- 捕まえた影は、持ち主が言えなかった言葉をぽつりと話す（短い影絵の演出）。
- 聞いた言葉は **「ことば帳」** に記録され、いつでも見返せる。
- 持ち主に影を返すとき、言葉をどう伝えるかを選ぶ場面がある（分岐はせず、反応が変わる程度）。

#### ランタンの成長（章が進むと解放）
| 章 | 能力 | 内容 |
| --- | --- | --- |
| 1 | 持つ・掛ける | 光を運ぶ／固定する |
| 3 | 青い炎 | 青い光で照らした影は **実体化** し、ルリが上を歩ける・押せるようになる（影の足場で隙間を渡る） |
| 4 | 光を投げる | 光の玉を遠くへ投げ、離れた場所を一時的に照らす |

### 3.4 謎解き

- 原則として **「光を置く場所を考え、影の形と通り道を組み替える」** 形式。例：
  - 街灯を消し、ランタンを別のフックに掛け替えて、影の逃げ道を一つずつふさぐ
  - ランタンを低い位置に置いて自販機の影を長く伸ばし、向かいの塀の影とつなげて影の橋をつくる
  - 鉢植えや看板を動かし、壁に「鍵穴の形の影」を映すと扉が開く（影絵パズル）
  - 青い炎で自転車の影を実体化させ、壊れた歩道橋の隙間を渡る
- アイテムは少数（同時所持 8 個まで）。「使う」は対象の前でアイテムを選ぶだけ。組み合わせは無し。
- 詰まり対策：ネムに話しかけると段階的なヒント（3 段階）。部屋ごとに「光をリセット」できる。

### 3.5 会話

- 画面下部のウィンドウに 1 文字ずつ表示。顔グラフィックは小さめ（48×48 px）。
- 選択肢は少数で、物語の分岐は無し（一本道）。会話の雰囲気が変わる程度。
- 一部の会話はウィンドウを出さず、キャラの頭上に吹き出しで表示（町の生活音的なつぶやき）。
- 影のセリフは白抜きの文字＋揺れる表示で、人のセリフと区別する。

### 3.6 収集要素（任意）

- 町中に小さな **「落とし影」**（猫や鳥、モノの影など、本筋に関係ない小さな影）が隠れている。
  捕まえると、その影が抱えていた小さなひとことがことば帳に増える。
- 全部集めるとエンディング後に短い追加シーン。

### 3.7 セーブ

- オートセーブ（エリア移動時・影を返したとき）＋ メニューから手動セーブ（3 スロット）。

## 7. アート仕様（ドット絵）

### 7.1 解像度

| 項目 | 値（仮） |
| --- | --- |
| 内部解像度 | **480 × 270 px**（16:9。1920×1080 / 3840×2160 では整数倍 ×4 / ×8 でぴったり表示。1280×720 など割り切れない解像度では ×2 で表示し周囲に黒帯） |
| Pixels Per Unit | 16 |
| タイルサイズ | 16 × 16 px |
| 主人公の身長 | 約 32〜36 px |
| 顔グラフィック | 48 × 48 px |
| フォント | 日本語ドットフォント（候補：DotGothic16〈OFL〉、PixelMplus〈M+ ライセンス〉）※ライセンス確認の上採用 |

### 7.2 カラー・雰囲気

- 基調色は **深い青〜群青〜紺**。差し色は街灯・窓明かり・ランタンの **暖色（橙・黄）**。
- 普通の影は紺色。**逃げた影は真っ黒＋輪郭がかすかに水色に光る**ことで、ひと目で区別できるようにする。
- 青い炎で実体化した影は、半透明の青い板のような質感。
- パレットは 32〜48 色程度に制限して統一感を出す（候補：自作パレットを `Assets/005_Textures/Palette.png` に用意）。
- 背景は 3〜4 層のパララックス（遠景の空・街並み・近景・手前の影）。

### 7.3 アニメーション

| 対象 | パターン |
| --- | --- |
| ルリ | 待機 4f、歩き 8f、小走り 6f、調べる 4f、ランタンを掛ける 6f、振り向き 2f |
| ネム | 羽ばたき 4f（常時ふわふわ追従。暗い部屋ではルリの背中に隠れる） |
| 逃げた影 | 待機 4f、移動 6f、驚く 3f、捕まる 6f（持ち主ごとに輪郭が異なる） |
| ルリの影 | ルリと同じ骨格で、動きだけ大げさ・いたずらっぽく |
| NPC | 待機 2〜4f＋固有の仕草 1 種（影が無い状態／戻った状態の 2 種） |
| 環境 | 雨、水たまりの波紋、街灯の明滅、湯気、蛾の群れ など |

### 7.4 ライティングと影の表現

- URP 2D ライトを使用。全体は暗めの Global Light（青）＋ 街灯・窓・ランタンの Point Light（暖色）。
- **影はドット感を守るため、Unity 標準の Shadow Caster 2D（ソフトな影）ではなく、自前の「影スプライト」で描く。**
  光源との位置関係から、影の長さ・向きを 16px 単位の段階で切り替える（例：短・中・長の 3〜4 段階）。
- ドット感を崩さないよう、ライトの影響はシンプルに（ノーマルマップは使わない予定）。

## 8. サウンド仕様

| 種類 | 方針 |
| --- | --- |
| BGM | ピアノ・ローファイ・アンビエント中心。エリアごとに 1 曲＋影を追う場面用 1 曲＋影の言葉の場面用 1 曲。全 8〜10 曲 |

## 9. 技術仕様

### 9.1 現在のプロジェクト状態

- Unity 2022.3.34f1、URP 14.0.11（**3D 用テンプレート**：Plane / Directional Light のみのシーン）。
- 入力は旧 Input Manager（`activeInputHandler: 0`）。
- スクリプトはまだ無し。

### 9.2 必要な変更（M0 で実施）

1. URP を **2D Renderer**（`Renderer2D` アセット）に切り替え、URP アセットに設定する。
2. パッケージ追加：
   - `com.unity.2d.sprite`、`com.unity.2d.tilemap`（＋任意で `com.unity.2d.tilemap.extras`）
   - `com.unity.inputsystem`（ゲームパッド・キー設定変更のため）
   - `com.unity.cinemachine`（カメラ追従・部屋の境界制御）
3. Main Camera に **Pixel Perfect Camera**（480×270, PPU 16）を設定。
4. スプライト取り込み設定の標準化：Filter Mode = Point、Compression = None、PPU = 16。
5. 不要な 3D 要素（Plane、Ground.mat、TutorialInfo）を整理。

### 9.3 光と影のロジック（影グリッド）

- 各部屋を **16px 単位のグリッド** として扱い、マスごとに「明るい／暗い／影の橋／実体化した影」を計算する。
  - 光源（ランタン・街灯・窓）は半径と遮蔽物から、照らすマスを決める。
  - 影を落とすモノ（`ShadowCaster`）は、光源の位置に応じて影のマスを伸ばす。
- 逃げた影はこのグリッド上の **暗いマスだけ** を経路探索（BFS）して、ルリから遠ざかるように動く。
- 光や物の配置が変わるたびにグリッドを再計算する（1 部屋あたり最大 30×17 マス程度なので負荷は軽い）。
- 見た目の影スプライトも同じグリッド結果から選ぶため、**「見た目の影」と「判定」が必ず一致** する。
- 謎の設計・デバッグ用に、エディタ上でグリッドの状態を色分け表示するギズモを用意する。

### 9.5 主要クラス設計

| クラス | 役割 |
| --- | --- |
| `GameManager` | ゲーム状態（探索中／会話中／影の演出中／メニュー）の管理。シングルトン |
| `PlayerController` | 左右移動・小走り・入力受付。状態が「探索中」以外なら操作を止める |
| `Interactable`（抽象） | 調べる対象の基底。`Talk` / `Inspect` / `UseItem` などを派生で実装 |
| `Lantern` | ルリが持つ光源。持つ／掛ける／外す。章に応じた能力（青い炎・投げる）の解放 |
| `LightSource` | 光源の共通クラス（ランタン・街灯・窓）。半径・色・点灯状態を持つ |
| `LanternHook` / `LightSwitch` | ランタン掛けと、街灯・窓のスイッチ |
| `ShadowCaster` | 影を落とすモノ。光源の位置から影のマスと影スプライトを決める |
| `ShadowGrid` | 部屋全体の明暗マスを計算・保持し、変化を通知する |
| `RunawayShadow` | 逃げた影の AI。暗いマスだけを経路探索し、ルリから逃げる。行き止まりで捕獲可能に |
| `ShadowWordData`（ScriptableObject） | 影の持ち主、言えなかった言葉、捕獲時の演出（Timeline）、ことば帳用テキスト |
| `WordJournal` | ことば帳。集めた言葉の管理と表示データ |
| `DialogueData`（ScriptableObject） | 話者・本文・選択肢・実行後のフラグ操作 |
| `DialogueRunner` / `DialogueUI` | 会話の進行と表示（TextMeshPro） |
| `Flags` | 進行フラグ（`Dictionary<string, bool/int>`）。謎の解決状況や会話分岐に使用 |
| `Inventory` / `ItemData` | アイテム所持と使用判定 |
| `SaveSystem` | フラグ・所持品・現在地・ことば帳・ランタンの位置を JSON で `Application.persistentDataPath` に保存 |
| `AudioManager` | BGM / 環境音 / SE のクロスフェード再生 |

- 会話・影の言葉・アイテムは **ScriptableObject でデータ化** し、コードを書かずに内容を増やせるようにする。
- 会話量が増えた段階で、外部ツール（Ink / Yarn Spinner）の導入を再検討する。
- 影の言葉の演出や章の区切りのイベントは **Unity Timeline**（導入済み）で組む。

### 9.6 品質目標

- 1080p で 60fps 固定。低スペック PC（内蔵 GPU）でも動作。
- ロード時間：シーン切り替え 1 秒以内（フェード演出で隠す）。
- 主要ロジック（影グリッドの計算、影の経路探索、フラグ、インベントリ、セーブ）は Test Framework で EditMode テストを書く。

## 付録 A. 参考作品と差別化

| 観点 | 『アンリアルライフ』（雰囲気の参考） | BlueNight（本作） |
| --- | --- | --- |
| 主人公 | 記憶を失った少女 | 記憶はある。「言えない」ことを抱えた少女 |
| コアメカニクス | モノに触れて、その記憶を見る | 光の置き場所で影を操り、逃げた影を追いつめる |
| 物語の軸 | 失った記憶と約束をたどる | 町じゅうの「言えなかった言葉」を届け、最後に自分の本音と向き合う |
| 謎の解き方 | 記憶で得た情報を使う | 光と影の配置そのものを組み替える（空間パズル） |

- 影を使った謎解きは他作品（例：『Contrast』『Schim』）にもあるため、
  **「光が影をせき止める追いつめパズル」＋「影が持ち主の本音を運んでいる」** という組み合わせで差別化する。
- 本作はキャラクター・ストーリー・固有の設定・素材をすべてオリジナルとし、
  既存作品のキャラクター名、シナリオ、グラフィックの流用は行わない。
